# UE4.27 — настройка общего материала ландшафта и дорог

## Что добавлено в код

В `ASmoothVoxelOctreeWorld` появился флаг `bEnableSurfaceMaterialBlending`. Он по умолчанию выключен, чтобы старые материалы проекта не начали неожиданно использовать каналы масок. Включай его после создания и назначения общего материала.

Когда флаг включён, ландшафт и дороги используют один материал меша. Вес каждого слоя вычисляется в коде и записывается в вершины. Соседние ячейки смешиваются гладкой функцией на расстоянии одного базового блока; ровно на общей границе получается 50/50. На дальних LOD переход может выглядеть шире из-за меньшей плотности вершин.

Маски:

| Слой | Канал | Смысл |
|---|---|---|
| Plains / равнина | Остаток веса | Базовый слой |
| Desert / пустыня | Vertex Color **R** | Вес пустынного слоя |
| Forest / лес | Vertex Color **G** | Вес лесного слоя |
| Snow / снег | Vertex Color **B** | Вес снежного слоя |
| Asphalt / асфальт | Vertex Color **A** | Вес асфальта |
| Soil / грунт | Texture Coordinate **UV channel 1**, компонент **R** | Вес грунта / грунтовой дороги |

Для каждого семпла сумма весов равна 1. Вес равнины рассчитывается как остаток:

`W_Plains = saturate(1 - (R + G + B + A + UV1_R))`

## 1. Создай главный материал

1. В Content Browser нажми **Add → Material**, назови материал `M_LandscapeBlend`.
2. Открой материал. Оставь **Material Domain = Surface**, **Blend Mode = Opaque**, **Shading Model = Default Lit**.
3. Добавь по одному узлу **Texture Sample Parameter2D** для Base Color каждой поверхности. Назови параметры:
   - `Plains_BaseColor`
   - `Desert_BaseColor`
   - `Forest_BaseColor`
   - `Snow_BaseColor`
   - `Asphalt_BaseColor`
   - `Soil_BaseColor`

   В каждый узел назначь соответствующую текстуру. Эти параметры — входы для твоих текстур; сам код не может автоматически превратить готовые отдельные Material assets в слои без ручной настройки их текстур.

4. Добавь **Vertex Color**. Его выход RGBA содержит четыре веса. Добавь **Texture Coordinate**, укажи **Coordinate Index = 1**, затем **Component Mask** с включённым только **R** — это вес Soil.
5. Собери веса:
   - `W_Desert = VertexColor.R`
   - `W_Forest = VertexColor.G`
   - `W_Snow = VertexColor.B`
   - `W_Asphalt = VertexColor.A`
   - `W_Soil = TexCoord[1].R`
   - `W_Plains = Saturate(1 - (W_Desert + W_Forest + W_Snow + W_Asphalt + W_Soil))`

6. Для Base Color умножь цвет каждой текстуры на её вес через **Multiply**, после чего сложи шесть результатов через **Add** и подключи сумму к входу **Base Color** материала. Такой способ удобен для нескольких слоёв и использует уже нормализованные веса.
7. Для первого теста подключи константу **Roughness = 1**. Когда переходы заработают, добавь roughness-текстуры каждого слоя и смешивай их теми же весами. Normal maps позже смешивай через **BlendAngleCorrectedNormals** либо эквивалентную функцию UE4, а не складывай tangent-space normals обычным Add.
8. Нажми **Apply**, затем **Save**.

### Важное про UV и масштаб

У меша уже есть UV0 для основной текстуры, с проекцией, выбранной по ориентации поверхности. Используй **Texture Coordinate Index 0** для тайлинга текстур. Начни с UV0 напрямую; масштаб и triplanar-проекцию лучше настраивать после проверки масок. UV1 здесь зарезервирован для веса грунта — не используй его как UV-развёртку грунтовой текстуры.

## 2. Назначь материал миру

1. Открой `BP_OctreeWorld` (или тот Blueprint, в котором используется `ASmoothVoxelOctreeWorld`).
2. В Details найди **Voxel → Rendering → Terrain Material** и назначь `M_LandscapeBlend`.
3. В **Voxel → Materials** включи `Enable Surface Material Blending` (`bEnableSurfaceMaterialBlending`).
4. Для этого режима не назначай отдельный материал на каждый биом: используется общий `TerrainMaterial`, а тип поверхности выбирается масками. Когда выключишь флаг, вернётся старое назначение отдельного материала на биом и раздельных секций дорог.
5. Сохрани Blueprint и карту, перезапусти генерацию мира или запусти новую игру, чтобы чанки построились заново.

Если Details показывает старое сохранённое значение свойства, используй **Reset to Default** для `Road Surface Offset`: теперь значение по умолчанию — **0 cm**. Старые значения, сохранённые непосредственно в Blueprint, могут перекрывать C++ default.

## 3. Дороги: принятые правила

- Асфальтовое ядро магистрали — 16 блоков; обычной дороги — 8; грунтовой — 4.
- Края асфальта получают прерывистый дополнительный ряд полноразмерных грунтовых ячеек: короткие отрезки по 1–2 блока, затем разрывы. Поэтому фактическая ширина на отдельных отрезках достигает 18/10 блоков для асфальтовых дорог. Это не должно сужать асфальтовое ядро.
- Дорожная поверхность остаётся гладкой по высоте, но плотность дороги занимает полный объём от поверхности примерно на один базовый блок вниз. Природный грунт над дорожной площадкой вырезается в том же SDF, а не остаётся поверх дороги.
- Дорожный меш остаётся частью ландшафтных чанков и использует их коллизию. Отдельные тонкие полигоны не являются дорожным полотном.

## Проверка

После назначения материала сначала проверь небольшой участок с четырьмя границами: plains↔forest, plains↔snow, soil↔asphalt, asphalt без грунтовой вставки. На границе между двумя слоями ожидается мягкий переход и приблизительно 50/50 у самой границы. Затем проверь ровный городской участок вдоль X и вдоль Y, пересечение дорог и высотный перепад. На дальнем LOD смешивание может растягиваться по поверхности из-за более редких вершин.

Материал `M_LandscapeBlend` нужно создать в редакторе Unreal: репозиторий пока содержит C++ поддержку масок и эту инструкцию, но не сгенерированный бинарный `.uasset` главного материала.
