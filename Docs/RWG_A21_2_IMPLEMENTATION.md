# A21.2-inspired Random World Generation plan

Target baseline: **7 Days to Die Alpha 21.2 Stable**, Unreal Engine 4.27, C++ generation with Blueprint-facing settings/debugging.

## Important fidelity boundary

The original RWG implementation is not available in this repository. We can reproduce documented A21-era behavior and calibrate against maps generated by the target build, but cannot promise bit-identical output without the original algorithm, assets, and exact configuration. Current-generation 7DTD documentation must not be used as if it were an A21 specification.

## Pipeline

1. **Deterministic world coordinates and settings**
   - Seed + map size + generator version + all generation settings define a stable world.
   - Use independent seeded noise channels so adding one feature does not reshuffle all other features.
   - Preserve the same generated result when chunks stream in different orders.
2. **Terrain and climate fields**
   - Continental-scale height, hills/ridges, detail, temperature, moisture, and water mask.
   - Four A21 RWG biomes: Forest, Desert, Snowy Forest, Wasteland.
   - Expose debug sampling and map previews for comparison.
3. **Map-level terrain features**
   - Lakes/lowlands and terrain transitions.
   - Roads are a planned graph/tile pass, not independent per-chunk random decoration.
4. **Settlements and districts**
   - Deterministic hub locations and footprints.
   - City/town/rural/wilderness zones; road grids and connectors must be generated as a coherent map layout.
5. **POI placement**
   - Data-driven prefab registry with bounds, biome eligibility, zone eligibility, min/max counts, spacing, road frontage, terrain slope, rotation, and placement score.
   - Placement decisions are made at map-generation time, not when a chunk happens to load.
6. **Surface details**
   - Biome-specific ground layers, vegetation, debris, resources, and decorations.
7. **Validation**
   - Generate fixed seeds at 4096x4096 target size.
   - Export heightmap, biome map, roads, hubs, and POI coordinates.
   - Compare against maps generated in Alpha 21.2: biome-area ratios, height distributions, road connectivity/length, settlement spacing, POI counts, and visual overlays.

## Not implemented yet

Road graph/tile generation, hub/district generation, prefab/POI registry, exact A21.2 settings, map export/comparison tooling, and automated UE build verification. The current noise coefficients are provisional and require calibration; they are not claimed to be extracted from the game.
